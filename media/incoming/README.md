# Local media input

Place source videos here for local testing. Do not commit copyrighted or private source media.

Supported extensions: mp4, mov, m4v, mkv, webm, avi, mpeg, mpg.

Run from the repository root:

    python3 scripts/media_ingest.py --input ./media/incoming --output ./media/processed

Processed assets remain unpublished until rights, attribution, and loop quality are reviewed.
